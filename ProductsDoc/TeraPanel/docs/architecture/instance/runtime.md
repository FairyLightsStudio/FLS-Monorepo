# Runtime

运行时是 TeraPanel 中一个很重要的概念，它负责维护实例的生命周期。

在 terad 中，它实现了上层 Instance 抽象的部分接口。

在架构设计阶段，存在4种不同的运行时类型:

| 运行时类型 | 描述 | 适用场景/特点 |
|------------|------|---------------|
| **Systemd** | 利用 systemd 初始化系统在基于 Linux 的节点上管理服务，提供强大的进程管理和监控功能。 | Linux 系统，需要系统级服务管理 |
| **Container** | 利用容器化技术（例如 Docker、Podman）在隔离的环境中运行应用程序，确保在不同的部署场景中保持一致性。 | 容器化环境，需要环境隔离和一致性 |
| **Process** | 一种轻量级的进程管理器，可以直接在主机系统上运行应用程序，适用于无法/不想使用容器化的限制。 | Windows、macOS 等非容器化环境 |
| **Nginx** | 专门用于托管静态网站和 PHP 应用程序，提供高效的网络服务功能。 | 静态网站和 PHP 应用程序托管 |


可以根据实际需要添加新的运行时类型。

Instance 模块可以通过 Runtime 为用户提供一致的界面和操作体验，无论应用程序运行在何种环境中。
