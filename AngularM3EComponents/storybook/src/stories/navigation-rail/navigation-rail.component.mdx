## Getting Started

### 1. Configure Angular Material

Configure Angular Material in your application styles. Navigation rail consumes the generated `--mat-sys-*` runtime variables and does not provide a Sass theme mixin.

### 2. Import the module

<Source
  language="ts"
  code={`import { MAT_NAVIGATION_RAIL_MODULES } from '@fairylights-studio/ngx-m3-navigation-rail';
import { MatExtendedFabCollapsedDirective } from '@fairylights-studio/ngx-m3-button';
import { MatIconModule } from '@angular/material/icon';
import { MatBadgeModule } from '@angular/material/badge';
import { MatButtonModule } from '@angular/material/button';`}
/>

## Content Projection Directives

These structural directives control what gets projected into each `mat-navigation-rail-item`.

| Directive                  | Selector                    | Purpose                               |
| -------------------------- | --------------------------- | ------------------------------------- |
| `*matNavigationIcon`       | `[MatNavigationIcon]`       | Primary icon displayed in the item.   |
| `*matNavigationActiveIcon` | `[MatNavigationActiveIcon]` | Alternative icon shown when `active`. |
| `matNavigationLabel`       | `[MatNavigationLabel]`      | Label text for the item.              |

## IoC & Framework Integration

`MatNavigationRailComponent` implements the `MatNavigationWidget` interface and registers itself via the `MAT_NAVIGATION_WIDGET` injection token. 

### Ideal Width Auto-Measurement
Upon startup, the component dynamically measures its ideal expanded layout width under a temporary, transition-blocked sandbox environment, caching the result to prevent layout jumps or text-wrapping during collapsible transitions. This ideal size signal is fully queryable by parent responsive containers.
