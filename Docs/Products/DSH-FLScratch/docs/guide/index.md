# 这是什么

DSH-FLScratch 的目标是**把 DeepSeek Harness 当成增强版 Scratch IDE 来用**：

- Scratch 负责可视化创作：积木、角色、舞台、即时预览；
- DSH 负责理解意图、读写项目文件、跑脚本、调用插件工具；
- 两者配合，让你用"说"的方式完成原本要在积木界面里点很多次的事情。

## 和原生 Scratch 的关系

不是替代。Scratch 的编辑器仍然是主要创作界面，DSH 在它旁边做增强：批量修改、跨角色重构、生成素材、写文档、整理数据之类。

## 现在有什么

- `dsh-scratch` 示例插件：演示如何给 DSH 注册工具（`scratch_echo`）并在卸载时清理，见[快速开始](/guide/start)；
- DSH 本身的会话、工具调用、文件编辑能力；
- 本仓库的文档站（你正在看的这个）。

## 规划中

- 直接在会话里打开/保存 `.sb3` 项目；
- 针对 Scratch 项目结构的专用工具（角色/造型/积木的增删改查）；
- 作品预览与本地运行；
- 常用任务的模板与提示词。

具体进度见[路线图](/guide/roadmap)。
