# 设计理念

## 积木优先，增强而非替代

Scratch 的价值在可视化：拖积木、看角色动起来、马上试。DSH-FLScratch 不重做编辑器，只补上编辑器不擅长的部分——批量操作、跨文件重构、脚本化、生成内容。

## 文件即真相

项目就是普通目录里的文件，DSH 的每次改动都落在文件上，可以 diff、可以回滚、可以提交 git。不做藏在应用内部、无法导出的私有格式。

## 本地优先，可审计

会话、工具调用、文件编辑都在你本地的环境里跑；每一步都留在会话历史里，事后能查"当时改了什么、为什么改"。

## 小步增强

先让"DSH + 插件工具 + 普通项目目录"这条链路稳定可用，再逐步加 Scratch 专用能力；每加一层都保持可解释、可退出。
