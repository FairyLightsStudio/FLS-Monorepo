# 设计理念

## 泰拉面板的目的

为用户解决项目部署中的最后一公里问题

泰拉面板致力于为开发者提供一个可信赖的，解决把软件发布到小白用户可能存在的种种问题的方案。

以前，你需要提供一份教程/视频啥的，让小白用户去安装你发布的项目。

即使是容器化技术，你可能也需要准备一份安装docker、配置镜像源的教程。

现在你可以在项目页添加一个 安装到泰拉面板 的badge，小白用户点击该badge即可跳转到自己的泰拉面板实例 ，后续安装流程的环境要求等等均由泰拉面板侧负责满足，用户侧做到在GUI上一键安装。

## 泰拉面板是什么

泰拉面板让用户通过更符合 **"人体工学"** 的方式（基于浏览器的 GUI 等等）进行日常运维。

泰拉面板意在兼容用户现有可用的计算设备。

## 泰拉面板不是什么

### 不是纯容器管理面板

如果你已经明确只使用容器技术运行软件，那么存在更适合你的选项，例如[只专注于 k8s 集群的定制版 Linux 系统](https://www.talos.dev/)。
